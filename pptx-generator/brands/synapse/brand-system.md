# Synapse — Brand System

> Dark ambient intelligence interface with cyan signal accents, glass depth, and explainable conversational flow.

---

## Brand Philosophy

### Core Principles

1. **Clarity Before Novelty**
   Keep hierarchy obvious and progression explicit. Every state should communicate where the user is and what happens next.

2. **Ambient Calm**
   Maintain low-noise visuals: restrained motion, deep desaturated surfaces, and measured contrast instead of loud decorative color.

3. **Traceable Intelligence**
   Present outputs with visible rationale and source context so synthesis feels inspectable, not magical.

| Name | Hex | Use |

## Typography

### Font Stack

- **Heading:** Space Grotesk (headlines, section titles, bold labels)
- **Body:** Plus Jakarta Sans (paragraphs, explanatory text, metadata)
- **Code:** Plus Jakarta Sans (monospace substitute is not part of the current Synapse system)

### Usage Guidelines

| Element | Font | Weight | Size |
|---------|------|--------|------|
| Display | Heading | 600 | 32-48px |
| H1 | Heading | 600 | 30-36px |
| H2/H3 | Heading | 600 | 20-24px |
| Body | Body | 400-500 | 14-16px |
| Micro labels | Body | 400-600 | 9-12px uppercase, tracked |

---

## Signature Elements

- Glass surfaces: translucent navy fills, thin cyan-tinted borders, soft depth shadow.
- Rounded geometry: 16-22px cards, 999px pills.
- Metadata language: uppercase micro-labels with wide tracking.
- Persistent conversational shell: one prompt rail adapting query → synthesize → refine modes.
- Explainability cues: relationship rationale, source blocks, inferred output shape.
