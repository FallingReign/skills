# FallingReign Skills

Agent skills maintained in this repository.

Current version: `0.1.0`

## Quickstart

Install from this repo with the same `skills.sh` flow used by Matt:

```bash
npx skills@latest add FallingReign/skills
```

Then choose the skills you want to install.

## Install Scripts

You can also use the helper scripts in this repo:

- Bash: `./scripts/install.sh`
- PowerShell: `./scripts/install.ps1`

Both scripts support an optional skill argument:

```bash
./scripts/install.sh video-producer
```

```powershell
./scripts/install.ps1 video-producer
```

## Skills

- [`video-producer`](./skills/video-producer/SKILL.md): Produce long-form AI video preproduction packages with storyboard + shotboard workflow.
